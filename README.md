# Semester Code Archive

Archive structure for Assignment II.

## Status

This repository is a scaffold, not a completed assignment. Original source code has not yet been supplied. Per-problem explanations and judge results must be completed from the actual submissions.

The official README template was referenced but not attached; the current problem README files use a provisional structure.

## Organization

- `On-Site_Examinations/`: regular and bonus UVa problems.
- `Before-Class_Exercises/`: optional LeetCode exercises.
- `After-Class_Practices/`: optional LeetCode practices.
- `Problems.md`: supplied semester problem schedule, including midterm and advanced challenges.
- `Assignment_Requirements.md`: supplied archive requirements.

Weekly folders cover every assigned problem in the main schedule. Unspecified later on-site problems are not invented. Midterm and advanced challenge lists remain in `Problems.md` pending source submissions and classification.
